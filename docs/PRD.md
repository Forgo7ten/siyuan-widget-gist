## 1. 产品定位与功能边界

### 1.1 核心目标

`siyuan-widget-gist` 是面向思源笔记的独立原生挂件（`NodeWidget`），支持在文档中嵌入并展示 GitHub Gist 远程代码片段：

1. **原生挂件接入**：通过思源内置 `/挂件` 菜单插入，一个 Gist 对应一个独立的 `NodeWidget` 挂件块，同一篇文档支持插入多个相互独立的挂件实例；
2. **常驻地址栏与直觉提交**：顶部地址输入框常驻显示且不隐藏；已保存配置时处于置灰只读锁定状态，编辑状态下高亮可输入，支持按 `Enter` 或鼠标焦点移开（`blur`）自动校验保存并刷新加载，按 `Esc` 取消编辑；
3. **块级属性持久化**：仅通过当前挂件块自身的 `custom-gist-url` 自定义属性保存规范化后的 HTTPS Gist `.js` 嵌入地址，随思源文档原生持久化与同步；
4. **沙箱隔离渲染与明暗主题样式融合**：在隔离的内层沙箱 `iframe` 中渲染 GitHub 官方 Gist 嵌入内容，并叠加适配思源浅色与深色主题的卡片、行号、代码排版与语法高亮样式；请求失败时按指数退避策略自动重试（2 秒起步、翻倍增长、单次上限 60 秒、最多自动重试 10 次）；
5. **双向高度自适应**：挂件高度跟随 Gist 真实内容与顶栏高度动态增减，避免固定高度产生内部纵向滚动条或截断内容。

### 1.2 功能边界 (Scope)

| 维度 | 包含 (In Scope) | 不包含 (Out of Scope) |
|---|---|---|
| **宿主形态** | 思源原生独立挂件（`NodeWidget`），使用内置 `/挂件` 入口插入 | 思源插件（不依赖 OmniKit 或其他插件）、`NodeCustomBlock`、额外代码块/结果块、专用 `/gist` 斜杠命令 |
| **输入与解析** | Gist 网页链接、`.js` 嵌入链接、标准 `<script src="..."></script>` 嵌入标签，以及 `?file=...` 单文件参数 | 任意第三方域名脚本、内联恶意脚本执行、历史特殊修订短链或非标准 HTML 片段 |
| **配置持久化** | 思源内核块属性 `/api/attr/getBlockAttrs` 与 `/api/attr/setBlockAttrs`（仅 `custom-gist-url`） | `localStorage`、工作区独立 JSON 配置文件、高度属性落盘、思源原生属性弹窗 |
| **内容渲染** | GitHub 官方 `.js` 嵌入脚本在内层 `sandbox="allow-scripts"` iframe 中隔离渲染，叠加适配思源明暗主题的定制 CSS | 自建代码解析器、自建 GitHub REST/GraphQL 客户端、私有 Gist Token 鉴权、Gist 创建与修改 |
| **加载与容错** | 打开文档自动加载、失败后最多 10 次指数退避重试（上限 60 秒）、手动刷新、修改 URL 自动刷新 | 加载成功后的周期性定时轮询、离线本地缓存、导出 PDF/HTML 静态化转换 |
| **布局与尺寸** | 常驻顶栏 + 随 Gist 内容及可用宽度变化双向自动调整高度，保留长代码行横向滚动 | 用户手动拖拽高度持久化、固定高度裁剪、自定义主题编辑器 |

## 2. 挂件接入、输入解析与数据存储

### 2.1 插入挂件与多实例隔离 (R01)

- **插入入口**：用户通过思源编辑器 `/挂件` 菜单选择 `siyuan-widget-gist`（显示名称 `GitHub Gist`）插入挂件块；
- **多实例隔离**：每个挂件实例绑定其所在 `NodeWidget` 块的 `data-node-id`；同一文档中多个挂件实例的 URL 配置、加载状态、退避计时器与高度调整彼此独立，互不干扰。

### 2.2 地址输入、规范化校验与自动保存 (R02)

挂件顶部常驻显示单行地址输入框，未配置时直接处于可编辑状态（占位提示为 `粘贴 GitHub Gist 链接或嵌入代码，回车或移开焦点自动加载`），不设独立的确认或保存按钮：

1. **支持的输入格式**：
   - Gist 页面地址：`https://gist.github.com/<user>/<gist_id>`
   - Gist 脚本地址：`https://gist.github.com/<user>/<gist_id>.js`
   - 标准嵌入标签：`<script src="https://gist.github.com/<user>/<gist_id>.js"></script>`
   - 单文件指定参数：上述任意格式附带 `?file=<filename>` 查询参数
2. **解析与安全过滤规则**：
   - 允许用户直接粘贴完整的标准 `<script>` 嵌入标签，但仅从中提取 `src` 属性值，绝不将用户粘贴的 HTML 或脚本直接注入宿主页面执行；
   - 协议必须为 `https:`，主机名必须严格匹配 `gist.github.com`，拒绝包含用户名密码凭据或非标准端口的 URL；
   - 路径必须匹配 `/<用户名>/<GistID>`、 `/<用户名>/<GistID>.js` 或 `/<GistID>[.js]`，缺少 `.js` 后缀时自动补齐；
   - 仅保留合法非空的 `file` 查询参数，剥离其余查询参数与 `#hash` 片段；
3. **提交与反馈（`Enter` 与失焦 `blur` 双触发）**：
   - 在编辑状态下，用户按下 `Enter`（非输入法组合输入状态）或将鼠标焦点移开输入框（`blur`）时，自动触发提交判定：
     - **首次未配置且输入为空**：移开焦点时不提示错误，保持可编辑空状态等待后续输入；按 `Enter` 时提示输入有效地址；
     - **已配置且编辑后内容与已保存 URL 一致**：移开焦点时直接退出编辑态并恢复输入框置灰锁定样式，不发起多余的保存请求；按 `Enter` 时退出编辑态并重新加载当前 Gist；
     - **输入了新的有效 URL**：调用内核接口保存规范化 URL，保存成功后将输入框切换为置灰只读锁定状态，并立即加载新 Gist；
     - **输入格式不合法或内核保存失败**：保持输入框处于可编辑高亮异常状态，保留原已保存配置与已渲染内容不变，并在状态区显示简短错误提示。

### 2.3 块属性持久化约束 (R03)

- **唯一存储属性**：仅使用当前挂件块的思源块自定义属性 `custom-gist-url`；
- **属性值规范**：属性值为规范化后的 HTTPS `gist.github.com` `.js` 嵌入地址（如 `https://gist.github.com/Forgo7ten/e0c40452cf8a0e8e4a9691136596a991.js`）；
- **落盘判定基线**：以思源内核接口 `/api/attr/getBlockAttrs` 和 `/api/attr/setBlockAttrs` 返回 HTTP 200 且 JSON `code === 0` 为唯一成功标准。`getBlockAttrs` 请求失败时提示读取异常，不误判为未配置状态。

## 3. 自动加载与失败退避重试

### 3.1 初始化与自动加载 (R04)

- **启动分流**：文档打开及挂件初始化时读取本块 `custom-gist-url` 属性：
  - 已存在合法 URL：回填规范化地址至常驻输入框并将其设为置灰只读锁定状态，自动加载远程 Gist 内容，无需用户额外点击；
  - 属性为空：输入框保持可编辑状态等待用户输入；
  - 已保存属性值无法通过 URL 校验：输入框处于可编辑状态并回填原值，提示用户修正；
- **单次请求边界**：Gist 渲染成功后停止一切定时器，不执行周期性后台轮询；仅在重新打开文档、用户点击「刷新」或保存新 URL 时重新发起请求。

### 3.2 指数退避自动重试 (R05)

当远程 Gist 脚本加载失败或超时时，挂件自动启动指数退避重试：

1. **重试次数与退避梯度**：
   - 首次加载失败后，最多执行 **10 次自动重试**（连同首次请求共最多 11 次尝试）；
   - 等待间隔从 **2 秒**开始，每次失败后翻倍，单次等待上限为 **60 秒**：

| 自动重试序号 | 第 1 次 | 第 2 次 | 第 3 次 | 第 4 次 | 第 5 次 | 第 6 次 | 第 7 次 | 第 8 次 | 第 9 次 | 第 10 次 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| **失败后等待时间** | 2 秒 | 4 秒 | 8 秒 | 16 秒 | 32 秒 | 60 秒 | 60 秒 | 60 秒 | 60 秒 | 60 秒 |

2. **计时与终止规则**：
   - 每次退避等待从上一次加载失败被确认的时刻开始计时；
   - 任意一次重试加载成功，立即清除重试状态并展示 Gist 内容；
   - 连续 10 次自动重试全部失败后，停止自动请求，状态区显示最终失败提示（如 `加载失败，已达重试上限（10/10），请刷新或编辑 URL`），同时保持右侧「刷新」与「编辑」按钮可用；
   - 等待重试期间，状态区实时展示当前退避进度（例如 `加载失败，8 秒后重试（3/10）`）；
   - 页面卸载或挂件被删除时，立即清理活动的加载超时与退避定时器。

## 4. 工具栏交互、编辑流转与高度自适应

### 4.1 界面布局与核心状态

挂件顶部采用一体化的常驻地址与工具栏布局，输入框始终保留在顶栏左侧，通过视觉层级区分**编辑态**、**置灰锁定态**与**折叠摘要态**，右侧提供「刷新」与「编辑」图标按钮（适配思源明暗主题）：

```text
1. 未配置状态（输入框处于可编辑态）：
   [ </> 粘贴 GitHub Gist 链接或嵌入代码...      [编辑中] ] [刷新(禁用)] [编辑(激活)]

2. 已配置展示状态（输入框常驻、置灰只读锁定，无状态标签）：
   [ </> https://gist.github.com/.../....js               ] [刷新] [编辑]
   ┌────────────────────────────────────────────────────────────────────┐
   │ GitHub Gist 内容（叠加思源明暗主题适配样式）                         │
   └────────────────────────────────────────────────────────────────────┘

3. 编辑 URL 状态（输入框高亮可编辑，原 Gist 内容继续保留可见）：
   [ </> https://gist.github.com/.../....js      [编辑中] ] [刷新] [编辑(激活)]
   ┌────────────────────────────────────────────────────────────────────┐
   │ 原 GitHub Gist 内容继续显示，回车或移开焦点自动保存并刷新             │
   └────────────────────────────────────────────────────────────────────┘

4. 加载失败 / 退避等待状态（输入框置灰只读锁定）：
   [ </> https://gist.github.com/.../....js               ] [刷新] [编辑]
   加载失败，60 秒后重试（6/10）

5. 思源折叠状态（fold="1"，高对比度摘要条，不渲染下方代码块）：
   ┃ [ ▶ GitHub Gist ] https://gist.github.com/... [已折叠] [编辑]
```

### 4.2 手动刷新 (R06)

- **入口**：顶栏右侧「刷新」图标按钮（悬停提示 `刷新 Gist`）；未保存过任何有效 URL 时按钮处于禁用态；
- **行为**：已配置状态下点击后，立即取消当前正在进行的加载或退避等待定时器，将自动重试计数 `retryCount` 归零，并重新加载已保存的 `custom-gist-url`（若当前处于编辑状态且修改了地址，失焦自动触发保存与刷新；若地址未改动则直接刷新已保存 URL）。即使已达到 10 次重试上限，点击刷新仍立即开启新一轮加载序列。

### 4.3 编辑与锁定切换 (R07)

- **锁定态表现**：当存在已保存 URL 且未处于编辑模式时，输入框常驻显示规范化地址，设置 `readonly` 并呈现置灰柔和样式（不显示锁定态文字标签），单击不触发编辑以避免误触；
- **进入编辑态**：点击顶栏右侧「编辑」图标按钮（悬停提示 `编辑 URL`）或**双击输入框**，输入框解除只读、切换为高亮编辑样式并显示「编辑中」状态提示，自动聚焦全选当前 URL；编辑期间不卸载下方已渲染的 Gist 内容；
- **退出与保存**：
  - `Enter` 或鼠标焦点移开（`blur`）：自动执行校验与保存；保存新地址成功后切换回置灰只读锁定态，重置重试计数并立即刷新加载新 Gist（若当前挂件块处于思源折叠态，则仅保存地址而不加载下方代码）；若编辑期间未修改原地址便移开焦点，直接切换回置灰锁定态；若输入内容不合法，保持编辑态并显示错误提示；
  - `Esc`：当已有已保存 URL 时，取消当前未保存修改、恢复回填已保存的 `custom-gist-url`、清除错误提示并切换回置灰只读锁定态，不触发新请求；当挂件首次插入尚未保存过 URL 时，按 `Esc` 清空错误提示并保持输入框可编辑，不删除挂件块。

### 4.4 思源块折叠与展开适配 (R08)

- **折叠状态监听**：挂件实时同步所在思源 `NodeWidget` 块的 `fold="1"` 折叠属性（包含打开已折叠文档的初始化场景与运行期切换折叠/展开场景）；
- **折叠态摘要条表现**：当挂件块处于折叠状态（`fold="1"`）时，顶部常驻栏自动切换为高对比度「折叠摘要条」样式以抵消思源原生折叠透明度衰减——左侧展示 `▶ GitHub Gist` 标识与主题色强调左边框，中间以高对比度文字展示当前 Gist 地址，右侧隐藏刷新按钮并显示「已折叠」状态标签（保留编辑入口）；下方 Gist 代码块销毁沙箱 iframe 并停止后台加载与重试，挂件高度收缩为单行紧凑高度；
- **展开态恢复**：当用户展开挂件块（移除 `fold="1"`）时，顶栏恢复常规紧凑单行地址栏样式；若存在已保存的合法 `custom-gist-url`，立即重新加载并渲染下方 Gist 代码块，高度自动恢复为完整内容高度。

### 4.5 双向高度自适应 (R09)

1. **真实内容跟随**：挂件高度根据常驻顶栏、状态提示区以及内层 Gist 实际渲染高度之和动态计算；
2. **双向伸缩**：切换到长 Gist 或窗口变窄导致折行增高时，挂件自动增高；切换到短 Gist 或窗口变宽时，挂件同步缩小，不保留历史最大高度留白；
3. **滚动条边界**：正常展示状态下挂件内部不产生纵向滚动条，超长代码行保留横向滚动条；未配置、加载中与失败状态保持紧凑高度；
4. **零高度落盘**：高度仅在运行期同步至宿主容器 DOM 样式，不写入思源块属性数据库，重新打开文档时自动重新测量。

## 5. 验收标准 (Acceptance Criteria)

| 编号 | 验收场景 | 预期结果 |
|---|---|---|
| **A01** | 从 `/挂件` 插入 `siyuan-widget-gist` | 出现含常驻可编辑 URL 输入框与顶栏图标的独立挂件块，无额外内容块、无弹窗 |
| **A02** | 分别粘贴网页 URL、`.js` URL、标准 `<script>` 标签（含 `?file=` 参数）后按 `Enter` 或移开鼠标焦点 | 均自动提取并保存规范化 `.js` URL，保留 `file` 参数，输入框切换为置灰只读状态并自动加载对应 Gist |
| **A03** | 输入非法地址、非 `gist.github.com` 域名或内核保存失败 | 输入框保持编辑高亮态，不覆盖原配置，显示错误提示，不执行任何非法脚本 |
| **A04** | 关闭文档后重新打开 | 自动读取本块 `custom-gist-url`，输入框置灰只读显示该 URL 并自动渲染 Gist |
| **A05** | 同一文档插入两个不同 Gist 挂件 | 各自独立保存属性、独立编辑锁定、独立刷新与退避重试，互不干扰 |
| **A06** | 模拟连续网络失败 | 首次失败后依次按 2、4、8、16、32、60、60、60、60、60 秒退避，满 10 次重试后停止并展示终态提示 |
| **A07** | 退避重试期间任意一次加载成功 | 立即停止后续重试并展示 Gist，成功后无周期性刷新 |
| **A08** | 退避等待期间或达到 10 次上限后点击「刷新」 | 立即取消旧等待并重新加载已保存 URL，重试计数归零 |
| **A09** | 点击「编辑」或双击锁定输入框后修改并移开焦点 / 未改动移开焦点 / 按 `Esc` | 锁定态无提示标签且单击不误触；双击或点编辑进入高亮编辑态并展示编辑提示；修改后移开焦点自动保存切换置灰并刷新；未改动移开焦点直接恢复置灰；按 `Esc` 恢复原地址与置灰状态 |
| **A10** | 长短 Gist 切换、明暗主题切换或编辑器宽度变化 | 挂件高度自动双向增减，Gist 卡片与语法高亮随明暗主题协调切换，内容完整展示且无内部纵向滚动条 |
| **A11** | 卸载页面或删除挂件块 | 立即清理当前实例的定时器与消息监听，不继续发起后台重试 |
| **A12** | 粘贴恶意 HTML、内联脚本或非 GitHub 地址 | 校验直接拦截；远程 Gist 始终在 `sandbox="allow-scripts"` 隔离 iframe 中渲染，不污染宿主环境 |
| **A13** | 折叠与展开挂件块（`fold="1"`） | 折叠时顶栏切换为高对比度摘要条（显示 `▶ GitHub Gist`、主题色左边框、Gist 地址与「已折叠」标识，隐藏刷新按钮），下方代码块停止加载并卸载 iframe，高度收缩为单行；展开时恢复常规顶栏并自动加载渲染 Gist |
